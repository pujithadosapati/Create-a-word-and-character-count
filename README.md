# Word and Character Counter
## Project Description
The Word and Character Counter is a Python-based text analysis program that accepts a paragraph from the user and calculates the number of characters, words, sentences, and spaces.
## Objective
To practice Python string manipulation, basic text processing, and input handling.
## Features
- Counts total characters, including spaces and punctuation.
- Counts words using the `split()` method.
- Counts sentences using `.`, `!`, and `?` punctuation marks.
- Counts spaces in the paragraph.
- Handles empty input.
## Technologies Used
- Python 3
## How to Run
1. Download or clone this repository.
2. Open `word_counter.py` in a Python environment.
3. Run the program.
4. Enter a paragraph when prompted.
5. View the calculated statistics.
